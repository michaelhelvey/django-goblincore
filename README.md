# goblincore

An opinionated template for building modern fullstack applications with Django.

## Features

- common plugins (django-filter, channels, daphne (asgi), django rest framework)
- best practices (ServeStatic for simple file serving, custom user model with email/password & admin
  integration, modules for views and models instead of files, etc)
- testing: `pytest` integration over the Django default test cases for easy test development
- deep integration with modern JS tooling with `vite`. Tailwind/DaisyUI builtin
- AI: `AGENTS.md` instructions for quick integration with common agents tooling
